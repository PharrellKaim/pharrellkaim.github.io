# 👋 Welcome to My First Blog Post

This is the very first post in my personal developer blog. I built this project to deepen my understanding of modern frontend development and to create a space where I can document my journey as a developer. I enjoy helping others and building conceptual explanations of technology in a way that makes it easier to understand.

---

## 🚀 What I Built

I created my personal portfolio website using React. On top of that, I added a fully functional blog system that allows me to write posts in Markdown and automatically render them inside the application.

The main features include:

- Dynamic routing for blog posts using React Router and Hashrouter
- Markdown-based content management
- Frontmatter metadata (title, date, slug)
- Styled rendering with Tailwind Typography
- Syntax highlighting for code blocks
- A clean and responsive layout

---

## 🧠 Why I Built It This Way

I wanted a system that is:

- **Simple** – no heavy backend or CMS required  
- **Flexible** – I can just write Markdown files  
- **Fast** – everything runs directly in the frontend  
- **Developer-friendly** – easy to extend and customize  

Using Markdown allows me to focus on writing content instead of worrying about databases or complex infrastructure.

---

## 💡 What I Learned

While building this project, I learned a lot about:

- React routing and dynamic pages
- Github pages routing and the opportunities it gives to you
- Handling Markdown in the browser
- Styling readable content for long-form writing
- Managing project structure in a scalable way
